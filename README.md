# Snake Game

A simple Snake game built with Java Swing.

## Features

- Arrow-key movement
- Food spawning avoids the snake
- Score tracking
- Pause and restart controls
- Collision detection for walls and the snake's body
- Clean Swing startup on the event-dispatch thread

## Requirements

- Java Development Kit (JDK) 17 or newer

## Run locally

From the project folder:

```powershell
javac SnakeGame.java
java SnakeGame
```

## Controls

| Key | Action |
| --- | --- |
| Arrow keys | Move the snake |
| `P` | Pause or resume |
| `R` | Restart the game |
